# مِقياس

تطبيق عربي لتتبع الأكل والوزن، مبني بحيث يشتغل كتطبيق أندرويد حقيقي (APK) وكـ PWA على أي جهاز بنفس الوقت، وبدون سيرفر خاص — كل شي يشتغل من متصفحك أو من جوالك مباشرة.

## وش يسوي التطبيق

**تسجيل الوجبات**
- إضافة سريعة من مكتبة أطعمة جاهزة، أو أطعمة ووصفات تسويها بنفسك.
- معالج "وجبة سريعة" يركّب لك وجبة من بروتين + كارب بضغطتين.
- تعديل كمية أي وجبة مسجّلة بعد ما تضيفها (نص حصة، ضعف الكمية... إلخ) بدون ما تحذفها وتعيد تسجيلها.
- تسجيل وجبة بيوم سابق لو نسيت تسجلها وقتها.
- قوالب وجبات: احفظ وجبات يوم كامل كقالب وطبّقه بضغطة بأي يوم ثاني.

**تسجيل بالذكاء الاصطناعي**
- صوّر طبقك أو اكتب وصفه بالعربي، والتطبيق يقترح لك الصنف والسعرات.
- وضعين: مطابقة مع مكتبتك الشخصية، أو تقدير عام للقيم الغذائية حتى لو الصنف مو موجود عندك.
- يمر عبر Cloudflare Worker خاص بيك (`server/ai-proxy-worker.js`) عشان مفتاح الـ API يضل عندك أنت بس، وما ينكشف بكود التطبيق.

**تتبع الجسم**
- وزن الجسم مع رسم بياني للتقدم، وشريط تقدّم نحو وزنك المستهدف.
- مؤشر كتلة الجسم (BMI) بمقياس WHO الملوّن.
- نسبة الدهون والمقاسات، كلها قابلة للتعديل بأي تاريخ سابق.

**متابعة وتحفيز**
- عداد ستريك وأيام الأسبوع اللي سجّلت فيها.
- حلقة تقدّم يومية للسعرات والماكروز، وملخص أسبوعي.
- تتبع شرب الماء مع إضافة سريعة.

**تذكيرات وتكامل أندرويد** (تحتاج بناء APK أصلي، ما تشتغل بنسخة الويب)
- تذكير لتسجيل الوجبات، وتذكيرات ماء على مدار اليوم.
- ودجت بالشاشة الرئيسية يعرض تقدّمك اليومي.
- تكامل مع Health Connect (يكتب بيانات التغذية والماء لتطبيقات الصحة الثانية).
- زر الرجوع بالجوال يشتغل بمنطق طبيعي (يسكّر الشيتات المفتوحة أول، وبعدين يطلب ضغطة ثانية للخروج).

**عام**
- يشتغل بدون نت (Service Worker يخزن نسخة تعمل أوفلاين).
- مزامنة سحابية اختيارية (Firebase) لمشاركة بياناتك بين أكثر من جهاز.
- ثيم فاتح/غامق، وواجهة عربية بالكامل (RTL).

## البنية التقنية

```
miqyas-app/
├── docs/                    ← نسخة الويب/PWA — على GitHub Pages، وهذا اللي يقرأه
│   │                          التطبيق المثبّت على الجوال مباشرة (server.url بالإعدادات)
│   │                          — أي تعديل هنا يظهر بالتطبيق تلقائياً بدون إعادة تثبيت
│   ├── index.html
│   ├── css/styles.css
│   ├── js/                 ← core.js, app.js, food.js, home.js, progress.js, ai.js, reminders.js
│   ├── manifest.json       ← إعدادات الـ PWA
│   ├── sw.js                ← يخزن نسخة احتياطية للعمل بدون نت
│   └── icon-192.png / icon-512.png
├── www/                     ← نسخة احتياطية مبنية داخل الـ APK نفسه (offline fallback فقط)
├── android/                 ← مشروع أندرويد الأصلي (Capacitor) — أي تعديل هنا
│   │                          (صلاحيات، أيقونة، مكونات إضافية أصلية) يحتاج بناء APK جديد
│   ├── app/src/main/java/com/miqyas/app/   ← المكونات الإضافية المخصصة (الودجت، Health Connect)
│   └── app/src/main/AndroidManifest.xml
├── server/ai-proxy-worker.js  ← Cloudflare Worker يستضيفه المستخدم، يحمل مفتاح Gemini
├── .github/workflows/       ← بناء APK تلقائي عند كل Commit
├── capacitor.config.json    ← إعدادات التطبيق (فيه رابط GitHub Pages)
└── package.json
```

## الإعداد (مرة وحدة بس)

### 1) ارفع المشروع على GitHub
1. سوّي حساب مجاني على [github.com](https://github.com) لو ما عندك.
2. سوّي مستودع (Repository) جديد اسمه `miqyas-app` (خليه **Public** — GitHub Pages المجاني يحتاج كذا إلا لو عندك خطة مدفوعة).
3. ارفع كل ملفات هذا المجلد (بما فيها `.github` و `docs`) عن طريق "uploading an existing file" ثم Commit.

### 2) فعّل GitHub Pages
1. بصفحة المستودع: **Settings** ← **Pages**.
2. تحت "Build and deployment" اختر Source: **Deploy from a branch**.
3. اختر Branch: **main** والمجلد: **/docs**، ثم Save.
4. انتظر دقيقة وبيطلع لك رابط شكله: `https://اسم-المستخدم.github.io/miqyas-app/`

### 3) اربط التطبيق بالرابط
1. افتح ملف `capacitor.config.json` بالمستودع (زر التعديل ✏️ بواجهة GitHub).
2. بدّل رابط GitHub Pages بالرابط الحقيقي من الخطوة اللي فاتت.
3. احفظ (Commit) — هذا بيشغّل بناء APK جديد تلقائياً.

### 4) حمّل APK وثبّته
1. تبويب **Actions** ← افتح آخر بناء ← حمّل `miqyas-app-debug-apk` من Artifacts.
2. فك الضغط، انقل `app-debug.apk` لجوالك، وثبّته (وافق على "السماح من مصادر غير معروفة" لو طلبها).
3. كل مفتاح البناء ثابت الآن (`android/app/debug.keystore`) — يعني أي بناء جديد بعد كذا يتثبت فوق الموجود مباشرة كتحديث عادي، بدون ما تحتاج تحذف التطبيق وتفقد بياناتك المحلية وربط Health Connect وFirebase.

## بعد كذا: تعديلات الواجهة بدون إعادة تثبيت 🎉

عدّل أي ملف بمجلد `docs/` بالمستودع مباشرة (أو ارفع نسخة جديدة)، اضغط Commit، وانتظر دقيقة. التطبيق المثبّت بجوالك يحمّل النسخة الجديدة تلقائياً أول ما تفتحه وأنت متصل بالنت — بدون أي إعادة تحميل أو تثبيت.

تعديلات `android/` (صلاحيات، أيقونة، مكونات إضافية أصلية جديدة) مختلفة — لازم بناء APK جديد من تبويب Actions، وتثبيته على جوالك.

## ملاحظات مهمة
- **يحتاج إنترنت** أول ما تفتح التطبيق كل مرة عشان يجيب آخر نسخة — لو ما فيه نت، يفتح بآخر نسخة محفوظة عنده (بفضل Service Worker).
- بياناتك (وجباتك، وزنك، خطتك) تنحفظ محلياً بجهازك دايماً بغض النظر عن التحديثات، وتقدر تفعّل مزامنة السحابة من إعدادات التطبيق نفسه.
- هذا APK "تجريبي" (debug build) — يشتغل ١٠٠٪، بس لو تبي تنشره على متجر Google Play مستقبلاً يحتاج توقيع رسمي وخطوات إضافية.
