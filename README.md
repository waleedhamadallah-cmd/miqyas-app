# مِقياس — مشروع تطبيق أندرويد (APK)

هذا مشروع Capacitor حقيقي يحوّل تطبيق "مِقياس" (النادي والأكل) إلى تطبيق أندرويد فعلي (.apk) تقدر تثبته على جوالك مباشرة — وبعد إعداد بسيط لمرة وحدة، أي تعديل تسويه على التطبيق يظهر عندك مباشرة بدون ما تعيد تحميله أو تثبيته من جديد.

## الإعداد (مرة وحدة بس)

### 1) ارفع المشروع على GitHub
1. سوّي حساب مجاني على [github.com](https://github.com) لو ما عندك.
2. سوّي مستودع (Repository) جديد اسمه `miqyas-app` (خليه **Public** — GitHub Pages المجاني يحتاج كذا إلا لو عندك خطة مدفوعة).
3. ارفع كل ملفات هذا المجلد (بما فيها `.github` و `docs`) عن طريق "uploading an existing file" ثم Commit.

### 2) فعّل GitHub Pages
1. بصفحة المستودع: **Settings** ← **Pages**.
2. تحت "Build and deployment" اختر Source: **Deploy from a branch**.
3. اختر Branch: **main** والمجلد: **/docs**، ثم Save.
4. انتظر دقيقة وبيطلع لك رابط شكله: `https://اسم-المستخدم.github.io/miqyas-app/`

### 3) اربط التطبيق بالرابط
1. افتح ملف `capacitor.config.ts` بالمستودع (زر التعديل ✏️ بواجهة GitHub).
2. بدّل `https://YOUR-GITHUB-USERNAME.github.io/miqyas-app/` بالرابط الحقيقي من الخطوة اللي فاتت.
3. احفظ (Commit) — هذا بيشغّل بناء APK جديد تلقائياً.

### 4) حمّل APK وثبّته (آخر مرة تحتاج تسوي هالخطوة)
1. تبويب **Actions** ← افتح آخر بناء ← حمّل `miqyas-app-debug-apk` من Artifacts.
2. فك الضغط، انقل `app-debug.apk` لجوالك، وثبّته (وافق على "السماح من مصادر غير معروفة" لو طلبها).

## بعد كذا: التعديلات بدون إعادة تثبيت 🎉

عدّل ملف `docs/index.html` بالمستودع مباشرة (أو ارفع نسخة جديدة)، اضغط Commit، وانتظر دقيقة. التطبيق المثبّت بجوالك بيحمّل النسخة الجديدة تلقائياً أول ما تفتحه وأنت متصل بالنت — بدون أي إعادة تحميل أو تثبيت.

لو تبيني أنا أعدّل التطبيق: أرسل لي محتوى `docs/index.html` الحالي بمحادثة جديدة، قول لي وش تبي تضيف أو تغيّر، وبعطيك النسخة المحدثة تحطها مكانه وترفعها.

## ملاحظات مهمة
- **يحتاج إنترنت** أول ما تفتح التطبيق كل مرة عشان يجيب آخر نسخة — لو ما فيه نت، يفتح بآخر نسخة محفوظة عنده (بفضل Service Worker مضاف).
- بياناتك (وجباتك، تماريك، خطتك) تنحفظ محلياً بجهازك دايماً بغض النظر عن التحديثات، وتقدر تفعّل مزامنة السحابة من إعدادات التطبيق نفسه.
- هذا APK "تجريبي" (debug build) — يشتغل ١٠٠٪، بس لو تبي تنشره على متجر Google Play مستقبلاً يحتاج توقيع رسمي وخطوات إضافية.

## البنية
```
miqyas-app/
├── docs/                        ← الملف اللي يتحدث تلقائياً (هذا اللي تعدّل عليه!)
│   ├── index.html               ← كود التطبيق (HTML/CSS/JS)
│   ├── manifest.json            ← إعدادات PWA
│   ├── sw.js                    ← يخزن نسخة احتياطية للعمل بدون نت
│   └── icon-192.png / icon-512.png
├── www/index.html               ← نسخة احتياطية مبنية داخل الـ APK نفسه
├── android/                     ← مشروع أندرويد كامل (Capacitor)
├── .github/workflows/           ← أتمتة البناء التلقائي
├── capacitor.config.ts          ← إعدادات التطبيق (فيه رابط GitHub Pages)
└── package.json
```
